## Intel

We scan with `nmap` :

We will use the command below since a normal nmap scan only scans the most common ports.

```
nmap -p-  10.10.0.17
```

**Output:**

```
Starting Nmap 7.991 ( https://nmap.org ) at 2026-09-16 13:13 +0000
Nmap scan report for 10.10.0.17
Host is up (0.020s latency).
Not shown: 65534 closed tcp ports (conn-refused)
PORT     STATE SERVICE
5739/tcp open  unknown

Nmap done: 1 IP address (1 host up) scanned in 10.08 seconds
```

Since we found an unknown port , we will scan it to reveal it's services 

```
nmap -sV -sC -p 5739 10.10.0.17
```

**Output:**

```
PORT     STATE SERVICE VERSION
```
